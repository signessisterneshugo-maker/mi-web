# Prompts clave utilizados para la creación del portfolio

Este documento recoge los prompts más relevantes que se han utilizado durante la elaboración y mejora del portfolio profesional de Hugo Signes Sisternes. Sirve como referencia para entender la dirección creativa, técnica y narrativa del proyecto.

## 1. Prompt de diseño general del portfolio

"Crea una web de portfolio personal para Hugo Signes Sisternes, con estilo moderno, intenso y tecnológico. Quiero que sea una mezcla de portfolio, marca personal y experiencia digital. La web debe tener un enfoque académico y tecnológico, con una estética cyberpunk/profesional, con páginas separadas para sobre mí, trayectoria, intereses, futuro, contacto y una sección de IA. Hazla visualmente potente, con buen equilibrio entre texto, diseño y estructura."

### Objetivo
Establecer una base visual, narrativa y estructural para todo el sitio.

---

## 2. Prompt de revisión y mejora según rúbrica

"Dime qué mejorías harías según esta rúbrica y cambia lo que puedas. Quiero que la web quede más sólida en contenido, estructura, diseño y evidencia técnica. Haz una evaluación honesta y luego mejora lo que haga falta en la web para que quede más profesional."

### Objetivo
Identificar puntos débiles del proyecto y reforzar la parte de presentación yjustificación profesional.

---

## 3. Prompt para cambiar la imagen principal

"Cambia la foto del index por algo que se vea bien visualmente. Y en la página de sobre mí pon una imagen de Yveltal. Quiero que la web mantenga identidad propia y que las imágenes se vean bien y aporten estilo."

### Objetivo
Ajustar la identidad visual con imágenes más claras, con mejor presencia y cohesión con la temática del proyecto.

---

## 4. Prompt para mejorar la experiencia móvil

"Mejora toda la web en móvil y haz que se vea muy bien. Añade la parte que explique cómo se ha hecho la web, los pasos que ha pasado y todo eso. Quiero que toda la web quede de 10 en general y que la experiencia móvil sea fluida."

### Objetivo
Optimizar la experiencia en dispositivos pequeños y reforzar la narrativa del proceso de creación.

---

## 5. Prompt para la sección de GitHub / commits

"Lo del git para ver los commits no funciona. Hazlo más visual, tipo ramas y commits, para que la sección se vea muy bien incluso si la API falla. Quiero que quede visualmente fuerte y que no se vea vacío ni genérico."

### Objetivo
Corregir la sección de actividad de repositorio y convertirla en un elemento visual más sólido y robusto.

---

## 6. Prompt para documentación profesional del proyecto

"Explica en el README todo el proyecto, las páginas y cómo se ha hecho para que lo lea el profesor. Que quede de forma profesional, con estructura clara, explicación técnica y resumen del proceso de desarrollo."

### Objetivo
Hacer visible el valor del proyecto desde una perspectiva documental y académica.

---

## 7. Prompt para apoyar la narrativa de la parte de proceso

"Añade una parte en la web que explique cómo se ha hecho la página, por qué se eligió este enfoque y qué pasos ha seguido el proyecto desde el inicio hasta la versión final. Que se entienda el proceso de diseño y desarrollo."

### Objetivo
Hacer visible la evolución del proyecto para reforzar la parte de proceso y reflexión profesional.

---

## 8. Prompt para el refinado de la identidad final

"Haz una última mejora general para dejar todo más pulido, coherente y profesional. Revisa el contenido, la estructura, los estilos, la narrativa y los detalles visuales para que el conjunto se sienta completo y bien terminado."

### Objetivo
Realizar una revisión final de consistencia global para cerrar el proyecto con un resultando más sólido.

---

## Valor de estos prompts

Estos prompts han permitido:

- definir la identidad del portfolio;
- mejorar la estructura general del sitio;
- ajustar la marca visual con imágenes y estilos más adecuados;
- reforzar la parte móvil y la experiencia usuario;
- convertir el proyecto en algo más cercano a un producto digital completo;
- documentar tanto el proceso como el resultado final para un público académico y profesional.

## Conclusión

Los prompts más importantes no solo han servido para crear contenido visual, sino para orientar la evolución del proyecto como una pieza con intención, criterio y mejora continua. La web se entiende mejor si se considera un proceso iterativo de diseño, programación, revisión y documentación.
