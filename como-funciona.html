Cómo funciona esta web

No es una sola página bonita: es un sistema. Cada sección, cada estilo, cada interacción y cada dato responden a una idea de marca y de producto.

↩ Volver al inicio 💬 Contactar
marca HTML CSS JS API
01

Contenido

Cada página representa una parte de mi identidad: perfil, trayectoria, intereses, futuro, contacto. La estructura está pensada para que la marca se entienda por secciones.

02

Estilo

Las variables CSS y los temas visuales hacen que la web cambie de personalidad sin perder coherencia. El sistema visual está centralizado y se reutiliza.

03

Interactividad

Cursores, animaciones, menú móvil, cambio de tema, chatbot y controles del 3D aportan vida útil. La interactividad no es decorativa: explica la experiencia.

04

Datos reales

La web consume APIs, sincroniza información del clima y del repositorio de GitHub, y se conecta con el contacto para hacerla sentir viva y operativa.
